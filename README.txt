                             AllBinary Platform ChaiScript

What is it?

This repository contains code generated by the AllBinary Platform for support in ChaiScript.  
This repo is used to allow developers to skip the ChaiScript code generation step.

What are some example games with this ChaiScript code?

https://allbinary.itch.io (The downloads with "-chaiscript" in the filename are ChaiScript only builds. Currently that only includes nothing. Also the ChaiScript builds are not available on Google Play or other stores.)
